# A Little Place Called Us

Personal anniversary single page. Buka `index.html` langsung di browser; tidak perlu build step atau backend.

## Mengganti konten

Edit data di bagian atas `app.js`: `memories`, `rememberedThings`, `statistics`, `thingsILove`, `littleSurprises`, dan `letterParagraphs`. Susunan serta komponen halaman akan tetap sama. Tanggal akhir, nama pengirim, kalimat hero, dan kalimat penutup ada di `index.html`.

## Menambahkan musik

Taruh file audio (misalnya MP3) di folder `music` dengan nama `lagu-kita.mp3`, sejajar dengan `index.html`. Musik akan mulai saat tombol **Masuk** ditekan; tombol musik di kanan bawah bisa dipakai untuk jeda atau memutarnya lagi. Jika nama/lokasi file berbeda, ubah `musicSource` di bagian atas `app.js`. Gunakan file audio yang kamu punya hak untuk dipakai.

Ganti URL foto Unsplash pada `app.js` dan `index.html` dengan foto kalian. Untuk hasil terbaik, gunakan foto landscape untuk hero dan foto portrait atau landscape untuk kenangan; gambar dipotong dengan `object-fit: cover`.

Tanggal kenangan dan statistik sengaja berupa placeholder. Isi sesuai cerita kalian sendiri.
